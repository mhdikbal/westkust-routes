## Provenance chain

```text

-> scan or folio
-> document
-> page region
-> line or DOCX paragraph
-> transcription
-> translation
-> claim
-> model feature
```

## Citation rule

A published quantitative claim requires at minimum:

- repository;
- access number;
- inventory number;
- folio or stable scan sequence;
- quoted source text;
- transcription or translation version.
