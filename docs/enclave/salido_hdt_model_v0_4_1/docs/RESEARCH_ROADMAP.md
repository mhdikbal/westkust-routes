# Research and Engineering Roadmap

## Phase 1: complete structured extraction

- complete source-passage links for every row;
- extract all name variants;
- complete mine-feature and equipment vocabularies;
- resolve duplicate or uncertain personal names.

## Phase 2: constraint solver

- implement CP-SAT variables;
- load hard and soft constraints;
- generate multiple feasible scenarios;
- produce contradiction reports.

## Phase 3: production Petri net

- encode places, transitions, token colours, guards, and interruptions;
- calibrate against January–April 1682;
- compare observed and simulated event counts.

## Phase 4: Bayesian measurement model

- validate historical units;
- pair Hoffman and Vogel observations;
- estimate assayer effects and latent batch values;
- flag probable transcription errors.

## Phase 5: temporal knowledge graph

- publish people, roles, locations, events, objects, claims, and provenance;
- support Graph-RAG queries;
- link every answer to evidence.

## Phase 6: spatial and visual twin

- build topology before geometry;
- encode explicit distances in original units;
- distinguish evidenced, interpreted, and analogical geometry;
- add 3D visualization only after uncertainty is visible.

## Phase 7: scholarly release

- TEI XML text edition;
- CSV and Parquet datasets;
- JSON-LD or RDF graph;
- reproducible code;
- citation and versioning package.
